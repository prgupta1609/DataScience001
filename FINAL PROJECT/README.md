# Data Science001 Assignment

This repository contains my Week 1 Data Science assignment completed as part of my internship learning work at Celebal Technologies.

The notebook covers foundational concepts of Python, Linear Algebra, Statistics, and Probability using practical examples and visualizations.

## Files

- `week1_PriyaGupta.ipynb` - Completed Jupyter Notebook assignment
- `requirements.txt` - Required Python libraries to run the notebook

## Topics Covered

### Python Basics
- Data types and control flow
- Dictionaries, sets, and list comprehensions
- Exception handling
- Functions and lambda expressions

### NumPy
- Array creation and reshaping
- Indexing and slicing
- Element-wise operations
- Matrix multiplication and dot product

### Pandas
- Series and DataFrame operations
- `iloc` and `loc`
- Filtering and grouping
- Handling missing values

### Linear Algebra
- Vectors and matrices
- Matrix operations
- Eigenvalues and eigenvectors
- Singular Value Decomposition
- SVD and PCA connection

### Statistics
- Descriptive statistics
- Mean, median, standard deviation, range, and IQR
- Hypothesis testing
- Pearson correlation
- Regression evaluation metrics
- KS test and ADF test

### Probability
- Basic probability
- Conditional probability
- Bayes theorem
- Probability distributions
- Central Limit Theorem

### Model Monitoring
- Concept drift
- Covariate drift
- Population Stability Index

## How to Run

First install the required libraries:

```bash

```

Then open the notebook:

