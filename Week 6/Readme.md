MNIST Image Denoising using Convolutional Autoencoders is a deep learning project implemented in Python 3.13 that utilizes a Fully Convolutional Denoising Autoencoder (DAE) framework to eliminate heavy, synthetic Gaussian noise ($\mu=0.0, \sigma=0.5$) from handwritten digits. Built symmetrically using TensorFlow and Keras, the architecture preprocesses and reshapes raw PNG directories into standardized continuous arrays, channels them through consecutive Conv2D and MaxPooling2D layers to a highly compressed $(7, 7, 32)$ feature bottleneck, and cleanly reconstructs them back to their baseline configurations via matching UpSampling2D maps and a binary cross-entropy loss function. Optimized using the Adam algorithm over 10 epochs, the system displays clean convergence metrics ($\text{loss}: 0.0988$, $\text{val\_loss}: 0.0976$) and outputs flawless visual matrices that strip away dense ambient static while perfectly preserving the core geometric line structures of the original digits.
